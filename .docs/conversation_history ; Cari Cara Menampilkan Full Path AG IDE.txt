---

### 🤔 Kenapa Harus Mengedit File `.exe`?

Awalnya, modifikasi dicoba pada file JavaScript biasa milik Electron di `resources/app/out/` (`workbench.desktop.main.js` dan `jetskiAgent/main.js`). Namun, tampilan sidebar percakapan **tidak berubah sama sekali**.

Setelah diinvestigasi via Chrome DevTools Protocol (CDP):
- Antigravity IDE menjalankan binary backend bernama **`agy.exe`**.
- Binary `agy.exe` ini menjalankan *internal HTTP static server* di port dinamis (misalnya `localhost:61xxx`).
- **UI sidebar percakapan di-*load* langsung dari server `agy.exe` tersebut**, bukan dari file JS Electron biasa.
- Di dalam binary `agy.exe` (berukuran ~210 MB), Google menyematkan (*embed*) arsip **ZIP internal** yang berisi file aset web frontend UI (`main.js`).

---

### ⚙️ Apa Saja yang Dilakukan oleh `patch_agy.py`?

Skrip ini bekerja dengan teknik **Binary In-Place Patching** yang sangat presisi:

1. **Membuat Backup Otomatis**:
   - Menyimpan salinan asli ke `agy.exe.original` sebelum menyentuh file asli. Kapan pun ingin dikembalikan, file asli tetap utuh.

2. **Membaca Arsip ZIP di Dalam Binary**:
   - Menemukan offset ZIP di dalam file binary (offset `183,368,780` hingga `187,710,613`).
   - Mengekstrak file aset web `main.js` dari ZIP tersebut.

3. **Menyuntikkan Logika Baru ke `main.js`**:
   - **Full Path Resolver**: Mengubah nama folder biasa menjadi Full Disk Path (`D:\...\folder`).
   - **Redux Hook**: Menghubungkan ke `window.__REDUX_STORE__` agar percakapan proyek baru langsung terdeteksi path-nya secara dinamis.
   - **Tampilan Rata Kiri**: Mengubah style CSS komponen subtitle (`Bpc` / `tb`) menjadi **Rata Kiri**, truncate dari kiri (`direction: rtl; text-align: left`), dan menyisakan **ruang bernapas 25%** di kanan baris (`max-width: 75%`).

4. **Kompresi Ulang & Rekonstruksi Binary (Tanpa Merusak Struktur)**:
   - File JS hasil editan dikompresi kembali menggunakan algoritma raw DEFLATE (`zlib`).
   - Menggunakan teknik *comment padding* (`/* ... */`) agar ukuran terkompresi hasil patch **sama persis per byte-nya** dengan ukuran file original (`3,271,174 bytes`).
   - Memperbarui checksum **CRC-32** dan **Uncompressed Size** pada *Local File Header* dan *Central Directory Header* ZIP di dalam binary.
   - Memvalidasi integritas ZIP (`zv.testzip()`) dan memastikan total ukuran file `agy.exe` tetap presisi `210,725,528 bytes`.

Dengan cara ini, file `.exe` tetap valid, tidak *corrupt*, Windows Defender tidak menganggapnya rusak, dan tampilan sidebar Antigravity IDE langsung berubah permanen sesuai yang diinginkan.
